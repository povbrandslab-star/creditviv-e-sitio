# Creditviv-e · Paquete para Claude Code

## Qué hay aquí

- `PROMPT-para-Claude-Code.md`: el prompt para pegar en Claude Code.
- `html-limpio/`: las 5 páginas aprobadas, sin etiquetas del wireframe. Se abren con doble clic en el navegador y ya se puede navegar entre ellas desde el menú.
- `html-con-etiquetas/`: las mismas páginas con las notas internas en verde, como referencia.
- `fuente/`: los archivos originales del lienzo de diseño.

## Pasos con GitHub

1. Crea un repositorio nuevo en GitHub, por ejemplo `creditviv-e-sitio`.
2. Clónalo en tu computador y abre la carpeta en VS Code.
3. Copia dentro todo el contenido de este paquete.
4. Abre Claude Code y pega el prompt.
5. Cuando el sitio esté listo, haz commit y push.
6. En GitHub, entra a **Settings → Pages**. En «Build and deployment», elige la rama `main` y la carpeta `/ (root)`, y guarda.
7. Después de uno o dos minutos te aparece el link: `https://TU-USUARIO.github.io/creditviv-e-sitio/`. Ese es el link para el cliente.

Cada vez que hagas push, el link se actualiza solo en uno o dos minutos.
